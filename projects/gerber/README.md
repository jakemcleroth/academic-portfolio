# Gerber Statistic

This notebook implements and explores the Gerber statistic as a measure of co-movement and a replacement for Pearson correlation in portfolio optimisation. This is then compared against historical covariance and Ledoit-Wolf Shrinkage.

## Context

This was developed as a presentation, as part of a module on Themes in Quantitative Investing, to explain the statistic and demonstrate its properties.

## Reference

Gerber, S., Markowitz, H.M., Ernst, P.A., Miao, Y., Javid, B., & Sargen, P. (2022). *The Gerber Statistic: A Robust Co-Movement Measure for Portfolio Optimization.* Journal of Portfolio Management.
