# Value at Risk Assignments

Five assignments covering VaR estimation across a range of methods and asset classes. Each folder contains the full written report (PDF) alongside the code and excel.

## Assignments

| Folder          | Description                                                                                                                                                                                                                           |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `assignment_1/` | Normal linear VaR: systematic, stand-alone and marginal VaR disaggregation for interest rate and multi-currency equity portfolios, PCA-based VaR, and parametric alternatives using normal mixture and Student-t distributions        |
| `assignment_2/` | Historical simulation VaR: scale exponent estimation, comparison with normal linear VaR, GARCH/A-GARCH volatility-adjusted returns, filtered historical simulation, and portfolio VaR decomposition into systematic and specific risk |
| `assignment_3/` | Monte Carlo VaR: A-GARCH multi-step simulation (implemented in both R and C++), multivariate normal simulation with Cholesky decomposition, and normal mixture distributions for crash regime modelling                               |
| `assignment_4/` | Options portfolio VaR: historical and Monte Carlo methods, delta-gamma-vega Greeks approximations, hedging effects, and multivariate risk factor simulation using Cholesky decomposition                                              |
| `assignment_5/` | Model risk and backtesting: systematic VaR under different estimation methods, independence and coverage tests for VaR model validation                                                                                               |
