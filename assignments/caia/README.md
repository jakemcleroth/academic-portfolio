# CAIA Assignments

Three assignments from the Alternative Investments module (based on the CAIA level 1 curriculum) covering alternative investment strategies and quantitative analysis of real assets.

## Assignments


| Folder                   | Description                                                                                        |
| ------------------------ | -------------------------------------------------------------------------------------------------- |
| `hedge_fund_fees/`       | Generalised hedge fund fee calculator. Computes investor net returns and fund manager fees earned. |
| `mining/`                | Investigates the relationship between Impala Platinum's share price and the price of platinum      |
| `systematic_strategies/` | Historical backtest of systematic trading strategies                                               |
