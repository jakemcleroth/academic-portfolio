# Value at Risk (VaR) Module

This folder contains coursework and assignments for the **Value at Risk** module of my Master's program.  
The module is based on *Market Risk Analysis IV: Value-at-Risk Models* by **Carol Alexander**, and focuses on applying quantitative methods to measure and manage market risk through VaR modeling.

---

## 📘 Course Framework
- **Core Textbook:** *Market Risk Analysis IV, Value-at-Risk Models* – Carol Alexander  
- **Focus:** Development of soft skills alongside technical implementation. Each assignment was structured as a **formal report**, combining written analysis with quantitative modeling.  
- **Deliverables:** Reports, code (R/Python), and Excel workbooks — all neatly formatted and documented.

---

## 🧾 Coursework Requirements
Assignments emphasized both **professional presentation** and **technical rigor**, including:
- Written reports with:
  - Cover page, table of contents, headings, bibliography, and page numbers.  
  - Clear introduction and conclusion sections.  
- Integration of examples, case studies, and detailed calculations.  
- Documentation of Excel models:
  - All tables, graphs, and calculations properly labeled.  
  - Explanations of methodology and results.  

---

## 📂 Repository Contents
- `assignment1/` – VaR introduction, risk measurement frameworks.  
- `assignment2/` – Parametric (variance–covariance) approaches.  
- `assignment3/` – Historical simulation and scenario analysis.  
- `assignment4/` – Monte Carlo simulation methods.  
- `final_report/` – Integrated report covering multiple VaR methodologies and results.  
- `code/` – Supporting R/Python scripts for VaR calculation and visualization.  
- `excel_models/` – Excel workbooks with formulas, graphs, and documented calculations.  

---

## 🔑 Skills & Methods Highlighted
- Implementation of **parametric, historical, and Monte Carlo VaR** methods.  
- Understanding of **regulatory context** for VaR in risk management.  
- Report writing with professional standards (academic rigor + industry-style documentation).  
- Integration of statistical software (R, Python) with spreadsheet modeling (Excel).
